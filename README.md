# Piyush Portfolio Website

## Files
- `index.html` — website structure and content
- `style.css` — responsive styling, layout, typography and hover effects
- `piyush.jpeg` — profile photograph
- `rishtara-logo.jpg` — Rishtara Globals logo

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create or open your GitHub repository.
2. Upload `index.html`, `style.css`, and the complete `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for deployment. Your live URL will appear in the Pages section.

Update the two link placeholders in the assignment PDF after publishing. The website's LinkedIn URL is based on the public profile slug included in the supplied resume; verify it before submission.
